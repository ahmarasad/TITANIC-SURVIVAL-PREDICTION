How it works

The stack behind every prediction on this page.

Support Vector Machine

Finds the boundary that best separates survivors from non-survivors, with the widest possible margin between the two groups.

Scikit-learn

Trains the classifier and bundles preprocessing with it, so new passengers are prepared the same way as the training data.

FastAPI

Serves this page and the /predict endpoint, returning each answer as JSON in milliseconds.

Pydantic

Checks every request before it reaches the model: valid class, gender, port and non-negative numbers.

Machine Learning Pipeline

Form input becomes a one-row table, passes through preprocessing, and the SVM returns 1 for survived or 0 for not survived.
